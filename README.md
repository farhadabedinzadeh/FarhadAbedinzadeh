## Featured research project

### [SPECTRALIS VOL Analyzer](https://github.com/farhadabedinzadeh/Spectralis-vol-analyzer)

A research-oriented **Python pipeline** for analysing Heidelberg Engineering SPECTRALIS `.vol` OCT data using [EyePy](https://github.com/MedVisBonn/eyepy).

- Extracts B-scans, imaging metadata, retinal segmentations, and scan geometry.
- Generates **ILM–BM retinal thickness maps**, en-face projections, and NIR overlays.
- Implements **foveal-pit candidate localisation** and **nine-sector ETDRS thickness analysis**.
- Exports figures, numerical measurements, and batch reports for reproducible research.

**Explore:** [Source code](https://github.com/farhadabedinzadeh/Spectralis-vol-analyzer/blob/main/spectralis_vol_analyzer.py) · [Run in Google Colab](https://colab.research.google.com/github/farhadabedinzadeh/Spectralis-vol-analyzer/blob/main/notebooks/Spectralis_VOL_Public_Sample_Colab.ipynb) · [Example figures](https://github.com/farhadabedinzadeh/Spectralis-vol-analyzer/tree/main/examples/healthy_OS/figures)
